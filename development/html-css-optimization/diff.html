Правило

Не оптимизируем ради современности. Сначала устанавливаем, что именно объективно хуже: валидность, семантика, accessibility, сложность генератора, размер output, layout или поддерживаемость.

Findings

  1. CSS units: у reference units есть; преимущественно используется px. Замена единиц сама по себе не является оптимизацией.
  2. CSS architecture: существенного расхождения с upstream пока не обнаружено.
  3. HTML generation: наш template layer существенно сложнее статического HTML reference.
  4. Navigation: наиболее заметная дополнительная логика находится в Liquid, где структура дерева вычисляется несколькими проходами.

Следующий эксперимент

Сопоставить один и тот же набор контента с фактическим generated HTML и reference HTML, затем проверить output по HTML-стандартам и accessibility. Изменения production до этого этапа не вносить.
