# Media

Изображения должны быть частью HTML-контента, а их геометрия — известна браузеру до загрузки файла.

## Dimensions

Для каждого `img`, у которого известны естественные размеры, задаются одновременно `width` и `height`.

Значения должны соответствовать естественному соотношению сторон исходного изображения. CSS может менять отображаемый размер, например `width: 100%; height: auto`, но HTML-размеры сохраняют соотношение сторон и позволяют браузеру зарезервировать место до загрузки изображения.

Это относится не только к контентным фотографиям, но и к служебным изображениям, включая логотип.

## alt

У каждого `img` должен быть `alt`.

- Содержательное изображение получает краткое описание предмета или действия.
- Декоративное изображение получает пустой `alt=""`.
- Изображение внутри ссылки использует `alt`, соответствующий назначению ссылки.
- Логотип, являющийся ссылкой на главную, описывает сайт или его название.

`alt` не является местом для набора ключевых слов.

## Responsive images

Если одно изображение отображается в разных размерах, используем `srcset` и `sizes`, чтобы браузер мог выбрать подходящий ресурс.

Для вариантов одного и того же изображения сохраняем одно соотношение сторон. Если для разных экранов требуется различная кадрировка, используем `picture` с отдельными `source` — это art direction, а не обычный responsive resize.

У `picture` всегда остаётся резервный `img` с `src`.

## Loading

Критические изображения, особенно логотип и изображение, являющееся LCP, не откладываем через `loading="lazy"`.

Изображения ниже первого экрана можно загружать лениво через `loading="lazy"`, если это действительно уменьшает начальную загрузку.

`fetchpriority="high"` применяем только к действительно приоритетному изображению, а не массово ко всем изображениям.

## SEO

Используем обычный `img` с доступным через `src` URL. Изображение размещаем рядом с релевантным текстом; используем осмысленное имя файла и содержательный `alt`.

Для поисковой индексации изображения не заменяем `img` фоновым CSS-изображением.

Формат и размер файла выбираем по назначению: современные форматы и responsive images должны уменьшать передаваемый объём без заметной потери качества.

## Проверка

Для каждого изображения проверяем:

1. есть `src`;
2. есть корректный `alt`;
3. заданы `width` и `height`, если известны естественные размеры;
4. соотношение сторон не меняется случайно при загрузке;
5. для адаптивных вариантов корректны `srcset` и `sizes`;
6. критические изображения не имеют необоснованного `loading="lazy"`;
7. имя файла и окружающий текст соответствуют содержанию изображения.

Главный критерий: после загрузки изображения страница не должна менять геометрию только потому, что браузер впервые узнал размеры картинки.
